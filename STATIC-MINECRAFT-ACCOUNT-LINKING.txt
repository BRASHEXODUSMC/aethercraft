AETHERCRAFT STATIC MINECRAFT ACCOUNT LINKING
============================================

This version can link an existing Minecraft Java username from a website opened
with VS Code Live Server.

WHY THE OLD REQUEST FAILED
--------------------------
The Mojang endpoint can return HTTP 200 while the browser still blocks access to
its response because it does not include Access-Control-Allow-Origin.

The account page no longer calls api.mojang.com directly.

CURRENT LOOKUP ORDER
--------------------
1. mc-api.io profile endpoint
2. mc-api.io UUID endpoint
3. PlayerDB
4. php/profile-proxy.php when the site is on a PHP-capable server

WHAT IS SAVED
-------------
The website saves these values in localStorage:
- Resolved Java username
- UUID
- Link date
- verified: false

The UUID is used to display the correct player skin with image fallbacks.

IMPORTANT SECURITY NOTE
-----------------------
This confirms only that the Minecraft profile exists. It does not prove that the
website member owns that Minecraft account.

For real ownership verification, use a Minecraft server plugin or backend that:
1. Generates a temporary code.
2. Requires the player to join the server or run a command with that code.
3. Confirms the UUID server-side.
4. Marks the account as verified only after the code matches.

LIVE SERVER TEST
----------------
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Start loader.html or index.html with Live Server.
4. Register or log in.
5. Open Account.
6. Enter a valid Java username.
7. Select Link Minecraft account.

If an older script is cached, press Ctrl+F5.
