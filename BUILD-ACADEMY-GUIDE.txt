IMPORTANT SCHEMATIC FORMAT NOTE
Native Java .schem/.schematic/.litematic and Bedrock .mcstructure/world formats are different binary/NBT/container formats. A browser-only HTML page cannot safely promise universal lossless conversion without dedicated parsers and version-aware block-state translation. The included Blueprint Lab is intentionally honest: it converts the documented AetherCraft JSON blueprint format and common identifiers locally in the browser. It never uploads the file.

To add native schematic support later, connect this UI to a trusted backend or vetted parser libraries and implement per-format readers/writers plus block-state mappings for each supported Minecraft version. Keep uploads size-limited, parse in an isolated worker/service, reject malformed archives/NBT, and never execute uploaded content.
