CUSTOM CONTENT MIGRATION

Add-on → ItemsAdder / Nexo Lab

Normalize common custom-item JSON/YAML definitions into starter configurations for ItemsAdder or Nexo. Target baseline: Minecraft Java 26.3 stable. Complex mechanics still require manual review.

Safe converter scope: this tool converts common item metadata—namespace/id, base material, display name, lore, custom model data/model path and texture references. Scripts, Bedrock behavior packs, Java code, custom entities, complex predicates, recipes with plugin-specific mechanics, furniture and animations are flagged for manual work instead of being falsely converted.
