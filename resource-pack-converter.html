CompatibilityFlags Java-only models, CIT/OptiFine, shaders, custom fonts or other assets requiring manual adaptation.

Important conversion notes

Bedrock uses different directory structures, metadata, UV layouts and animation definitions. Some entity/block textures need UV reconstruction or TGA alpha handling, and advanced held-item rendering can require Bedrock attachables, animations and render controllers. The report identifies those cases so the output is never silently misleading.
